# AniSyns — iPhone-застосунок (.ipa) зі збіркою в GitHub Actions

Усередині: Python-сервер (`anime_app.py`) + вікно WebView, яке показує інтерфейс. Збирається на віддаленому Mac у GitHub Actions, тож локальний Mac не потрібен.

## Крок 1. Репозиторій на GitHub
1. Зареєструйся на github.com (безкоштовно) і натисни **New repository**.
2. Назва будь-яка, наприклад `anime-ios`. Видимість:
   - **Public** — збірки безкоштовні й без ліміту, але код усі бачать;
   - **Private** — код прихований, але безкоштовний ліміт на macOS-збірки малий (орієнтовно 10–15 збірок на місяць).
3. Розпакуй цей архів на ПК. У репозиторії на сторінці **Add file → Upload files** перетягни **весь вміст** папки (теки `src`, `resources`, `.github` і файли `pyproject.toml`, `LICENSE`, `README.md`) → **Commit changes**.
   - Якщо тека `.github` не перетягується (вона прихована): **Add file → Create new file**, у назві введи `.github/workflows/build-ipa.yml` і встав туди вміст цього файлу.

## Крок 2. Збірка
1. Вкладка **Actions** → зліва **Build IPA** → **Run workflow** (збірка також стартує сама після кожного завантаження файлів).
2. Чекай ~10–25 хв. Зелена галочка — успіх.
3. Відкрий завершений запуск → внизу **Artifacts** → завантаж `AniSyns-ipa` (це zip з `AniSyns.ipa`, розпакуй).
4. Якщо червоний хрестик: відкрий запуск, натисни на невдалий крок, скопіюй останні ~60 рядків помилки й надішли мені.

## Крок 3. Установка на iPhone з Windows
**Sideloadly (простіше):**
1. Встанови iTunes та iCloud з сайту Apple (не з Microsoft Store), потім Sideloadly (sideloadly.io).
2. Підключи iPhone кабелем, довірся комп'ютеру.
3. На iPhone: Налаштування → Конфіденційність і безпека → **Режим розробника** → увімкнути, перезавантажити.
4. У Sideloadly перетягни `AniSyns.ipa`, введи свій Apple ID, натисни **Start**.
5. На iPhone: Налаштування → Загальні → **VPN і керування пристроєм** → свій Apple ID → **Довіряти**.

**Обмеження безкоштовного Apple ID:** застосунок «живе» 7 днів, потім його треба підписати знову тим самим способом (дані зберігаються). Одночасно не більше 3 таких застосунків. Sideloadly вміє оновлювати автоматично, поки ПК і iPhone в одній мережі. AltStore теж підходить і оновлює підпис сам.

## Де файли
Відео, `library.json` і кеш лежать у **Файли → На iPhone → AniSyns → AniSyns**. Туди можна перекинути `library.json` і скачані серії з Carnets.

## Важливі обмеження
- **iOS призупиняє застосунок у фоні** (через ~30 с після виходу). Завантаження і сервер зупиняються, коли ти виходиш з застосунку чи блокуєш екран. Для завантаження тримай застосунок відкритим. Пауза завантажень лишається в стані, і після повернення можна продовжити.
- ffmpeg на iPhone недоступний. HLS-серії збирає вбудований збирач (H.264 + AAC). Зашифровані потоки (рідкісні) і HEVC не підтримуються. Для превʼю-кадрів із відео використовуються картинки з сайтів.

## Dynamic Island і фонова робота
- Папка `LiveIsland/` (Swift-код + скрипт `add_island.rb`) додається у збірку автоматично кроком «Add Dynamic Island». Якщо цей крок або збірка з ним не вдається, workflow сам збирає звичайну версію без острова (дивіться попередження в логах Actions).
- Для Dynamic Island у Sideloadly потрібні 2 App ID (застосунок + розширення) — безкоштовний Apple ID має ліміт 10 нових ID на тиждень.
- Тримання застосунку у фоні робить тихе аудіо (налаштування «Робота у фоні»).
